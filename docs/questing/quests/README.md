# PlanQuesting Quest Dossiers

One dossier per reviewed quest belongs in this directory. Create it from
[`QUEST_DOSSIER_TEMPLATE.md`](../QUEST_DOSSIER_TEMPLATE.md) and follow
[`ADDING_A_QUEST.md`](../ADDING_A_QUEST.md).

The dossier is the support and validation record. Its declared support state is
authoritative; presence in this directory alone does not mean that live
automation is enabled or runtime validated.
